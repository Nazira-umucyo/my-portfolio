HOW TO RUN
In VS Code: install the "Live Server" extension, right-click index.html, choose "Open with Live Server".
Or just double-click index.html. No install needed.
(Fonts load from Google Fonts, so they need internet. Without it the page uses your system font.)

FILES
index.html   the page
style.css    colors and layout (colors are at the top of the file)
script.js    your projects list and the animations
cv.pdf       ADD THIS: your CV, named exactly cv.pdf (the Download CV buttons use it)
images/      ADD THESE (all optional, the page works without them)
             photo.jpg            your photo for the home screen
             <project id>.png     a screenshot for each project card

PROJECT IMAGE NAMES (images folder)
bond-system.png, or360i.png, smart-rwanda.png, innerglow.png, eventwave.png,
alu-bridge.png, hospital-management.png, igirepay.png, social-media-api.png, malaria-cnn.png

HOW TO EDIT A PROJECT
Open script.js. The list at the top has one block per project. Change the text,
add or remove stack items, add links. Leave role as "" to hide "What I did".

PUT IT ONLINE (free, GitHub Pages)
1. Create a GitHub repo, upload all files (index.html, style.css, script.js, cv.pdf, images folder).
2. Repo Settings > Pages > Deploy from branch > main > / (root) > Save.
